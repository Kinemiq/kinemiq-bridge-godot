KinemIQ Bridge for Godot 4
===========================
1. In Godot: Asset Store > Import... > pick this zip > Install (or unzip it into your project folder) - you get addons/kinemiq_bridge.
2. In Godot: Project > Project Settings > Plugins > KinemIQ Bridge > Enable.
3. In KinemIQ Studio (https://kinemiq.app/studio/): Export > Send to Godot.
   The animation arrives as res://kinemiq/<name>.glb - drag it into a scene, its AnimationPlayer plays it.
Listens on 127.0.0.1:8768 only (this computer). Sends nothing anywhere. https://kinemiq.app
